# 🚀 PatternForge 2026

A structured and pattern-based approach to mastering Data Structures and Algorithms.

This repository focuses on solving problems by identifying core patterns such as Two Pointers, Sliding Window, Binary Search, and more.

---

## 📌 Goals

* Build strong problem-solving skills
* Master DSA patterns instead of random practice
* Prepare for top tech interviews
* Maintain clean and optimized solutions

---

## 🧠 Patterns Covered

* Two Pointers
* Sliding Window
* Binary Search
* Arrays & Strings
* Linked List
* Graphs
* Dynamic Programming (coming soon)

---

## 📂 Structure

Each folder represents a specific pattern.
Problems are named using:

```
lc-<problem-number>-<problem-name>.py
```

Example:

```
lc-125-valid-palindrome.py
```
